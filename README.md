# Browser Search Page

A minimal HTML, CSS, and JavaScript experiment: enter a search term and click **Search** to navigate to Google results.

## Run locally

Open [w.html](w.html) in a browser. No installation or build step is required. An internet connection is needed to load search results.

## How it works

The single HTML file contains the layout, styling, and click handler. Non-empty input is added to a Google search URL and the current page navigates there.

## Project scope

An early browser-interface exercise. It is a search launcher, not a standalone browser or search engine. Query handling is basic and currently replaces spaces without fully URL-encoding other characters.
