Specific feedback.
Inspectable evidence.

SpeechTrace turns two short speech clips into aligned, explainable moments to listen to, with performer-authored rehearsal decisions.

Technical execution / 35%

The Python backend aligns MFCC features with dynamic time warping and maps estimated Vosk word times to the supplied transcript. Relative energy, pacing and contour feed a disclosed 40/40/20 rubric. The browser labels precomputed examples and supports fresh analysis through the same engine.

Innovation / 25%

Interval-level explanations connect acoustic differences to words and paired playback. An artist can mark a difference intentional; the tool keeps measured evidence separate from the performer's interpretation.

Design & polish / 25%

Keyboard-accessible controls, labeled result provenance, input invalidation, clear limits, mobile layout, exportable JSON and rehearsal notes. New annotations clear when the underlying analysis changes.

Presentation / 15%

The dedicated core walkthrough is under three minutes. The October 7 rehearsal additions are visible in the live app and release screenshot; the source video predates those additions. See the technical report for reproducible evaluation.
